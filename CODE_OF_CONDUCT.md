# Code of Conduct

## Expected behavior

Be respectful, constructive, and inclusive. Focus criticism on code and decisions, not people. Protect private DNS data and credentials in issues, pull requests, and logs.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, and publishing private information are not acceptable.

## Enforcement

Report conduct concerns privately to the repository maintainers through GitHub. Reports will be reviewed and handled in confidence where possible.
